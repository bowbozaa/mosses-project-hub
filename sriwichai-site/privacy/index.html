เอกสารนี้อธิบายว่าแอปพลิเคชันอัตโนมัติของ SRIWICHAI Film Studio (ต่อไปเรียก "เรา") เก็บและใช้ข้อมูลอย่างไร แอปนี้ถูกใช้เพื่อเผยแพร่วิดีโอต้นฉบับขึ้นช่อง YouTube ของเราเองเท่านั้น ในซีรีส์สารคดี "GENESIS CODE" โดยไม่เข้าถึงข้อมูลของผู้ใช้รายอื่นแต่อย่างใด

This document explains how the automated application of SRIWICHAI Film Studio ("we", "us") collects and uses data. The application is used solely to publish our own original videos to our own YouTube channel (the "GENESIS CODE" documentary series). It does not access, read, or modify any other user's data.

1. ข้อมูลที่เราเข้าถึง Data we access

  • โทเคนการยืนยันตัวตน (OAuth token) ของเจ้าของช่อง เพื่ออัปโหลดวิดีโอผ่าน YouTube Data API เท่านั้น
  • ข้อมูลของวิดีโอที่เราสร้างเอง ณ ตอนอัปโหลด ได้แก่ ชื่อคลิป คำอธิบาย แท็ก หมวดหมู่ และสถานะการมองเห็น

We access only the channel owner's OAuth token (to upload via the YouTube Data API) and the metadata of videos we produce ourselves — title, description, tags, category, and privacy status — at upload time.

2. สิ่งที่เราไม่ทำ What we do NOT do

  • ไม่เข้าถึง อ่าน หรือแก้ไขข้อมูล YouTube ของผู้ใช้รายอื่น
  • ไม่ขาย ไม่โอน และไม่ใช้ข้อมูลจาก YouTube API เพื่อการโฆษณา
  • ไม่เก็บข้อมูลส่วนบุคคลของผู้ชมวิดีโอ

We do not access other users' YouTube data; we do not sell, transfer, or use YouTube API data for advertising; and we do not collect personal data of viewers.

3. YouTube API Services Use of YouTube API Services

แอปนี้ใช้บริการ YouTube API Services เมื่อใช้งานแอป ถือว่าคุณยอมรับ YouTube Terms of Service และอยู่ภายใต้ Google Privacy Policy

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and your data is handled in accordance with the Google Privacy Policy.

4. การจัดเก็บและการเพิกถอน Storage & revocation

โทเคนถูกเก็บอย่างปลอดภัยและใช้เฉพาะเพื่ออัปโหลดวิดีโอของเราเท่านั้น เจ้าของช่องสามารถเพิกถอนสิทธิ์ได้ทุกเมื่อที่ Google Account · Third-party access

Tokens are stored securely and used only to upload our own videos. The channel owner may revoke access at any time via Google Account security settings.
